# 内容任务规划 Agent

小影校招 AI Agent 开发考核：内容任务规划 Agent。

## 当前状态

当前仅完成需求定义、架构设计和仓库骨架，便于创建 GitHub 仓库。尚无业务实现、模型调用、可执行测试或真实运行记录，不能作为完整考核交付。

历史文件 `PROJECT_PLAN.md` 为素材审核与发布排期方向的早期规划，仅供参考；本项目范围以 `docs/01-requirements.md` 为准。

## 目标

帮助运营人员在预算和截止时间内生成并保存内容活动方案；模型观察工具结果后可调整方案，保留已成功结果。

## 目录与评审入口

- `src/`：预留模型、决策循环、工具和状态存储模块。
- `tests/`：预留可执行测试，目前仅有验收清单。
- `examples/`：预留输入、实际输出及 Trace，目前无运行结果。
- `data/`：预留合成素材、工具费用和耗时规则。
- `docs/01-requirements.md`：范围与验收标准。
- `docs/02-solution.md`：基本架构和决策约束。
- `docs/03-evaluation.md`：待执行验证计划。
- `docs/04-ai-usage.md`：AI 使用说明与个人贡献待填项。
- `docs/05-retrospective.md`：复盘待填项。

## 环境与运行

尚未选定语言、模型或框架，无依赖需要安装；当前无需环境变量。业务运行命令将在实现 CLI 后补充，目前没有可运行的业务入口。建议先原生实现单 Agent + 本地工具，是否采用框架由后续实现决定。

## 后续最小实现顺序

1. 定义输入、方案、步骤状态和工具返回结构。
2. 实现四个本地工具及持久化、幂等约束。
3. 接入真实模型动作循环、步数限制及离线 Mock 入口。
4. 完成 CLI 和验收测试，生成真实输出及 Trace。
5. 更新评估、AI 使用记录和实际用时，提交 GitHub URL 与最终 commit SHA。

本阶段不扩展 UI、HTTP API、多 Agent、真实发布或生产部署。
