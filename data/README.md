# 合成资料预留目录

`catalog.json` 提供合成素材、制作方式、工具费用与耗时，全部为模拟值。

预算单位为整数模拟单位，时间单位为分钟。检索、估算、保存免费；每次成功生成脚本收费 1、耗时 1 分钟。生成器为本地模板，不调用真实生成模型。制作费用是尚未执行的方案费用，不作为工具实扣：premium=11、lean=6、micro=3。初始 premium 总额为 1+11=12；重新生成 lean 后总额为 1+1+6=8。

故障注入在执行前发生，不收费且不累计模拟耗时；参数或依赖拒绝亦不收费。生产执行未实现，不表示实际完成了内容制作。模拟时间按当前时钟加累计工具模拟耗时计算，不真实等待。
