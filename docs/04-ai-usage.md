# AI 辅助与个人贡献

## 使用方式与投入

本项目采用以AI辅助编码为主的vibe coding方式完成，实际投入约2个半小时（候选人估计，非精确工时统计）。使用Codex协助设计讨论、代码生成、测试执行和文档整理；运行时真实决策模型为deepseek-v4-pro。

## 个人贡献

本人承担了大部分需求与设计决策，包括确定考核范围、选择CLI及交互形式、明确自然语言追问与默认选择边界、确定文件接入方式，以及推动真实模型验证和交付材料完善。本人参与代码审核与修改，并通过实际CLI试用检查输入解析、执行流程和结果表现。

代码、测试和文档的大部分初稿由AI辅助生成和迭代，不将其描述为本人独立手写实现。个人贡献主要体现在需求判断、方案取舍、代码审核修改和使用反馈。

## AI承担的工作与验证

AI协助实现模型适配、动作校验、有限ReAct循环、四个本地工具、SQLite状态和幂等存储、自然语言交互及附件读取，并生成测试和评估文档。验证结果见examples/test-results.txt与docs/03-evaluation.md。

业务工具使用合成资料和模板；真实模型负责需求抽取与动作决策。Mock只验证流程。真实对话中发现短视频偏好未满足后调整提示并保留前后证据；独立真实报价场景验证模型观察12超预算后改选8。未提交密钥或模型内部思维过程。

AI协助增加显式续跑入口、边界校验与离线运行证据；累计投入按候选人说明更新为约2个半小时。
