# 实现架构与取舍

## 调用流程

CLI → 输入校验 → SQLite 请求身份检查 → Agent 模型决策循环 → 动作校验 → 工具事务 → 新观察回灌 → 下一次模型决策或终止。

原生 Python 3.11+ 标准库，不使用 Agent 框架，避免为本地四工具任务引入额外 Runtime。模型接口为 `decide(context)`，真实模型通过 urllib 调用兼容 chat-completions 的 HTTP 服务；离线 Mock 根据观察确定动作。两种模式共用 actions、agent、tools、storage。

## 模块与职责

| 文件 | 职责 |
|---|---|
| domain.py | 输入校验、请求指纹、状态枚举 |
| storage.py | SQLite 事务、请求身份、状态快照、已保存计划 |
| tools.py | 四工具、费用与耗时、依赖检查、故障注入 |
| actions.py | 严格动作白名单和参数校验 |
| models.py | 业务 Prompt、真实 HTTP 适配器、离线策略 |
| agent.py | 有上限的动作循环、观察回灌、Trace、结果重放 |
| cli.py | 参数、JSON 输入输出、Trace JSONL、退出码 |

## 动态决策

模型每轮得到当前状态、已有工具观察、当前估算和剩余调用次数，自行选择动作。执行器不写死工具序列。动作或模型调用失败会变成可观察的错误，下一轮可调整。模型只有 finish(reason) 表示未完成，不能直接指定 completed。

离线路径例：

- 正常：检索 → premium 脚本 → 估算 12（预算20）→ 保存。
- 超预算：估算 12（预算10）→ lean 脚本 → 估算8 → 保存。
- 工具失败：检索成功 → premium 脚本失败 → 保留检索结果并改 lean → 估算7 → 保存。
- 部分成功：检索仅返回部分可用素材 → 选择轻量方案；返回的部分成功标记保留在观察中。
- 不可行：估算有预算/时间缺口，找不到可行替代后 finish，状态 incomplete。

这些是实际 Mock 路径，不能替代真实模型决策验证。

## 费用与时间

规则见 data/catalog.json。费用总额 = 累计成功工具费用 + 当前方案尚需制作费用。失败注入、依赖拒绝不收费；替代方案不退还已花生成费用。制作费仅为方案预计费用，不是已经执行的付款。模型真实 API 费用属于独立成本，不纳入模拟单位。

时间使用当前时钟加累计工具模拟耗时，再加剩余制作时间；不等待模拟分钟。真实模式用真实时钟，Mock 可固定时钟。保存时重新计算预算与预计完成时间，防止只依赖旧估算。该估计不保证真实生产交付。

## 状态、依赖与持久化

步骤实际状态记录在 steps；历史成功/失败记录都保留。当前 script 每次成功生成增加版本并使旧 estimate 失效，历史估算仍保留在 steps/Trace。保存要求当前脚本和当前版本估算存在；素材快照保存在脚本 sources 中，后续检索不删除成功脚本来源。

保存计划、保存步骤和整体 completed 状态在一个 SQLite 事务提交，提交成功后才能返回完成。唯一 request_id 防止重复保存。请求指纹归一化时区，绑定主题、预算和期限；相同输入重放已有终态，不同输入返回冲突。结果重放保留原模式和模型标识，即使期限已过也可以读取原结果。

SQLite 使用事务和 revision 防止旧状态直接执行工具。定位单机 CLI 单执行者；未实现多进程完整调度租约。终态支持显式/resume或--resume续跑；异常中断遗留的 running 状态可在相同输入下继续，但不承诺所有中断窗口下的完整 Trace 恢复。

## 上限与记录

默认每次运行最多 16 轮模型决策、每个请求最多 12 条实际工具步骤；无效动作与模型异常计入轮次。超过限制返回 incomplete，保留已成功结果。模型 HTTP 超时默认60秒，单次可配置最大180秒；尚无整次运行的墙钟超时。

Trace 包含动作、参数、观察、简短依据与 next_action，不收集内部思维过程。模型错误摘要做脱敏；业务输入和素材仍可能出现在输出，提交仅使用合成数据。


## 交互层

chat.py管理终端会话、附件、需求摘要、追问、执行与重放。intake.py通过同一HTTP适配器的complete(system,context)抽取需求，输出经过类型和原输入校验；Mock只提供明确格式的离线解析。关键字段缺失不进入Agent。修正解析失败会清空当前草稿，避免误执行旧需求。

附件限制4个、每个128 KiB，仅支持UTF-8的txt/md/json。JSON素材schema校验后注入Tools，真实检索会返回附件来源；txt/md仅作为活动说明进入理解上下文。文件内容hash参与请求指纹，重放绑定同一素材版本。

自然语言解析调用独立于规划的16轮上限，受每条8000字符、总对话24000字符限制及单次HTTP超时约束。退出不会保存尚未执行的对话，终态修改需/new。执行前重新取时钟，模型等待耗时不能绕过期限检查。
