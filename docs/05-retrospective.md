# 复盘

## 投入与工作方式

实际投入约2个半小时，以AI辅助编码为主。本人负责主要需求与设计决策、代码审核修改，并实际试用CLI反馈问题；AI承担了较多代码、测试及文档生成工作。

## 难点与收获

费用重规划不能将已花费用清零。项目将工具实际费用与尚需制作费分开，替代方案仍累计脚本生成费；旧估算失效，保存前再次检查预算与期限。

跑通Mock不等于验证了真实模型。初期真实模型提前规避超预算，只能证明预算选择能力；后续加入参考价与最终报价不同的合成场景，才实际观察到模型12→8的重规划。应依据Trace判断能力，不能只看完成状态。

对话试用也暴露了偏好理解问题：模型曾忽略短视频偏好选择图文，提示调整后改选可行短视频。结构化摘要和实际内容形式展示让用户能在运行前后检查结果。

工程验证中处理了Windows临时目录权限与SQLite连接关闭问题，认识到环境和资源生命周期也影响可运行性。

## 限制与下一步

当前是单机CLI核心实现，脚本与分镜为本地模板；真实样本量较小，尚未系统评估稳定性。失败终态手动续跑已实现，见examples/resume。下一步优先增加复杂工具反馈下的真实模型测试和失败续跑，不扩展界面、部署或多Agent。
